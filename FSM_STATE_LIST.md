# Combined FSM State List

Use this file only after the four task drafts have been reviewed. For every state, record:

- State name
- Purpose of the panel
- Information displayed
- User input accepted
- Valid outgoing transitions
- Error behavior
- Back, Quit, or Logout destination

## Minimum combined states

1. Login
2. Client Menu
3. Client Account Information
4. Client Invoices
5. Client Payments
6. Client Shopping Cart / Order
7. Salesclerk Menu
8. Salesclerk Become Client
9. Manager Menu
10. Manager Confirmation
11. Manager Become Salesclerk

The team may combine simple operations into an existing state or add more sub-panels when the interaction changes substantially.
