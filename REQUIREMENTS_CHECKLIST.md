# Final Requirements Checklist

- [ ] The submission lists every FSM state.
- [ ] Every state has a short purpose description.
- [ ] The complete design has at least six panels.
- [ ] One complete state-transition diagram is included.
- [ ] The Login panel supports manager, salesclerk, and client authentication.
- [ ] Password checking is assigned to a separate Security object.
- [ ] The Client Menu contains only client operations.
- [ ] The Salesclerk Menu excludes manager-only operations.
- [ ] The Manager Menu includes price changes, shipments, and freeze/unfreeze.
- [ ] Every manager operation requires password confirmation.
- [ ] Salesclerk can become a valid client and return to Salesclerk Menu on logout.
- [ ] Manager can become a salesclerk and return to Manager Menu on logout.
- [ ] Sub-panels return to the correct parent panel.
- [ ] Back, Quit, and Logout transitions are shown where appropriate.
- [ ] Non-FSM aspects are identified.
- [ ] The implementation plan for non-FSM aspects is explained.
- [ ] State names and transition labels are consistent across all files.
- [ ] The final submission was reviewed by all four group members.
